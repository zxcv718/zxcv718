## 🙋 About

- 🧱 자료구조·시스템을 **밑바닥부터 직접 구현**하며 원리를 익힙니다 — Redis, Git을 내장 컬렉션 없이 만들어 봤어요.
- 🔁 같은 문제를 **다른 프레임워크로 다시 풀어보며** 설계 차이를 비교합니다 — NestJS → Spring Boot 포팅.
- 🤖 요즘은 **LLM 에이전트 + 권한 인식 검색(RAG/MCP)** 에 관심이 많습니다.
